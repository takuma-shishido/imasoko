# 02 公開ルーム一覧 `/public`

関連:[索引](./00_index.md) / [05 §3・§6](../05_feature-design.md)

## 目的

`public` に設定された有効なルームを一覧から探し、URLを知らなくても参加できるようにする。既定 private のため、ここに出るのは**明示的に公開されたルームだけ**。

## 遷移

- 入口:トップの[公開ルームを探す] / 直リンク `/public`
- 出口:
  - **カードをタップ** → `/r/:room_id`([03 参加フォーム](./03_join.md))
  - **[戻る]** → `/`

## レイアウト(mobile)

```
┌───────────────────────┐
│ ←  公開ルーム      ⟳    │  ← 戻る / 更新
├───────────────────────┤
│ ┌───────────────────┐ │
│ │ サッカー部 集合      │ │  ← title(無ければ「無名のルーム」)
│ │ 👤 5人 ・ 残り 1:23   │ │  ← members / expires_at から算出
│ │            [参加する]│ │
│ └───────────────────┘ │
│ ┌───────────────────┐ │
│ │ …                  │ │
│ └───────────────────┘ │
│                       │
│ (公開ルームがありません) │  ← 空状態
└───────────────────────┘
```

## 要素と挙動

| 要素 | 挙動 |
|---|---|
| リスト取得 | `GET /api/rooms/public` を初回取得。以後は手動更新(⟳)+ 任意で 10〜15秒ポーリング |
| カード | `title`(未設定は「無名のルーム」)/ `members` 人数 / `expires_at` からの残り時間 |
| [参加する] | `/r/:room_id` へ。参加フローは private と同じ([03](./03_join.md)) |
| 空状態 | 「いま公開されているルームはありません」+ トップへ戻る導線 |

## API

```
GET /api/rooms/public
  res : [ { room_id, title, members, expires_at }, ... ]   # active な public のみ
```

- サーバは**期限切れ・private を除外**して返す([05 §6](../05_feature-design.md))
- 位置など機微情報は一覧に含めない(参加して初めて `room_state` を受け取る)

## 状態・エラー

- 取得失敗:トースト+再試行(⟳)
- 残り時間 0:一覧から自然に消える(次回取得時)
- **プライバシー**:カードに「参加すると現在地が共有されます」を明示
