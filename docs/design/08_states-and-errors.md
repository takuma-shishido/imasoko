# 08 例外状態・エラー

関連:[索引](./00_index.md) / [dev-docs §5・§6・§8](../imasoko-dev-docs.md) / [02 §5](../02_technical-design.md)

各画面に共通する**異常系・終了状態**をまとめる。正常系は 01〜07 を参照。

## 状態一覧

| 状態 | 発生条件 | 表示 | 出口 |
|---|---|---|---|
| **ルーム期限切れ**(入室前) | `GET /api/rooms/:id` が `410 Gone`([dev-docs §5](../imasoko-dev-docs.md)) | 「このルームは終了しました」 | トップへ / 新規作成 |
| **ルーム終了**(入室中) | WS `room_expired` 受信([dev-docs §6・§8](../imasoko-dev-docs.md)) | 地図を閉じ「集合は終了しました」 | トップへ。再接続しない |
| **Not Found** | `GET /api/rooms/:id` が `404` | 「ルームが見つかりません(URLをご確認ください)」 | トップへ |
| **接続中/再接続** | WS切断 → 再接続中([02 §5](../02_technical-design.md)) | 上部「再接続中…」バー | 自動復帰(復帰時 `join` 再送) |
| **接続失敗(継続)** | 再接続が規定回数失敗 | 「接続できません」+ 再試行 | 手動再試行 |
| **位置情報 拒否** | Geolocation 許可ダイアログで拒否 | 「閲覧のみ」バッジ+許可し直し導線 | 位置なしで継続([02 §5](../02_technical-design.md)) |
| **位置情報 非対応/HTTP** | Geolocation 不可(HTTPS必須) | 「この環境では位置を取得できません」 | 閲覧のみで継続 |
| **圏外** | 自分/他人が全エリア外 or 選択エリア外([dev-docs §7](../imasoko-dev-docs.md)) | 端にクランプ+「圏外」/一覧にバッジ | エリア切替で解消し得る |
| **人数上限** | `max_members_per_room` 超過([02 §7](../02_technical-design.md)) | 「満員で参加できません」 | トップへ |
| **公開切替 権限なし** | 非host が `PATCH visibility`(通常UIは非表示) | 拒否(サーバ `host_token` 検証) | 無視/トースト |
| **汎用エラー** | 予期しない失敗 | トースト+再試行 | — |

## 設計方針

- **1クライアントの不正で全体を落とさない**:サーバはパース失敗メッセージを無視/エラー返却して継続([02 §5](../02_technical-design.md))
- **終了状態は明確に**:`room_expired` 後は地図・送信を止め、再接続もしない([dev-docs §6](../imasoko-dev-docs.md))
- **位置なしでも参加可**:拒否/非対応でも閲覧のみで成立させる([企画書 4.2](../imasoko-kikakusho.md))
- **プライバシー**:エラーメッセージや画面に生の座標・他者の機微情報を出さない

## 遷移(異常系)

```
GET /api/rooms/:id ─410─▶ 期限切れ画面 ─▶ /
                   ─404─▶ NotFound 画面 ─▶ /
WS 切断 ─▶ 再接続中バー ─(復帰)▶ 通常 / ─(失敗継続)▶ 接続失敗
WS room_expired ─▶ 終了画面(再接続しない) ─▶ /
```
