# 01 トップ画面 `/`

関連:[索引](./00_index.md) / [企画書 4.1](../imasoko-kikakusho.md) / [05 §3](../05_feature-design.md)

## 目的

アプリの入口。**ルーム作成**と**公開ルーム探索**の2導線のみを提供する。ログイン・インストール不要というコンセプトを体現し、迷わせない。

## 遷移

- 入口:URL直打ち / ブックマーク / 共有リンクのルート
- 出口:
  - **[ルームを作る]** → `POST /api/rooms` → 発行された `/r/:room_id` へ(作成者=host)
  - **[公開ルームを探す]** → `/public`([02](./02_public-rooms.md))

## レイアウト(mobile)

```
┌───────────────────────┐
│         いまそこ        │
│  集合、リンク一本で。    │
│                       │
│  ┌─────────────────┐  │
│  │   ルームを作る    │  │  ← 主ボタン(大)
│  └─────────────────┘  │
│  ┌─────────────────┐  │
│  │  公開ルームを探す  │  │  ← 副ボタン
│  └─────────────────┘  │
│                       │
│ ・ログイン不要/使い捨て  │
│ ・位置情報を共有します    │  ← 注意書き(一言)
└───────────────────────┘
```

## 要素と挙動

| 要素 | 挙動 |
|---|---|
| ロゴ/キャッチ | 静的表示(「集合、リンク一本で。」) |
| **[ルームを作る]** | 押下で `POST /api/rooms`(body:既定 `visibility:"private"`、`title` 未指定)。レスポンスの `host_token` を `localStorage`(キー例 `imasoko.host.<room_id>`)へ保存し、`/r/:room_id` へ遷移。二重押下防止(loading表示)。失敗時はトースト+再試行 |
| **[公開ルームを探す]** | `/public` へ遷移 |
| 注意書き | 「参加すると現在地がルーム内で共有されます」を一言 |

## API

```
POST /api/rooms
  req : { }                         # 既定 private
  res : { room_id, host_token, expires_at, visibility }
```

- 作成直後は **private**。公開化は参加後に設定シート([07](./07_room-settings.md))から行う
- `host_token` は以後の host 限定操作(公開切替)に必要。端末ローカル保存のみで、URLには含めない

## 状態・エラー

- 通信失敗:トースト「作成に失敗しました。もう一度お試しください」+ 再試行
- 作成連打:loading 中はボタン無効化
