# 04 ルームメイン(地図) `/r/:roomId`(参加後)

関連:[索引](./00_index.md) / [企画書 4.3・4.5](../imasoko-kikakusho.md) / [05 §1](../05_feature-design.md) / [dev-docs §6・§7](../imasoko-dev-docs.md)

## 目的

参加者全員の現在地をリアルタイムに地図表示する**中心画面**。ここから集合場所・建物・空き教室・共有・設定の各シートを開く。

## レイアウト(mobile)

```
┌───────────────────────┐
│[国際展示場][テレポート][ｷｬﾝﾊﾟｽ]1:58│ ← エリア切替 / 残り時間
├───────────────────────┤
│ 集合 7/5 14:30 ・◇3号館2F 約120m ✕│ ← 集合バー(いつ・どこに・常時。#38)
├───────────────────────┤
│                       │
│        [地図]          │
│    ● 自分   ◯ 他人      │
│         ◇ 集合          │
│  ◹ 圏外(端にクランプ)    │      ┌──┐
│                       │      │⌖ │ ← 現在地へ
│                       │      │▣ │ ← 全員表示
├───────────────────────┤
│  👤 5人  ─ 引き上げ ─    │  ← メンバー一覧ハンドル
│ [集合場所][建物][空き教室]│  ← 操作バー(シートを開く)
│ [共有][設定]      [退出] │
└───────────────────────┘
```

## 要素と挙動

| 要素 | 挙動 |
|---|---|
| **エリア切替**(`AreaSwitcher`) | 国際展示場駅 / 東京テレポート駅 / 有明キャンパスを切替(狭い画面では「国際展示場 / テレポート / キャンパス」等に短縮表示)。自分の現在地から `resolveArea()` で初期自動選択。切替でSVG差し替え+全ピン再投影([05 §1](../05_feature-design.md)) |
| **地図**(`MapView`) | Leaflet `CRS.Simple` + 選択エリアのSVGを `imageOverlay`。ピン=自分(強調)/他人(名前+階)/集合(別形)/圏外(グレー・端クランプ・「圏外」, [dev-docs §7](../imasoko-dev-docs.md)) |
| 自分の位置送信 | `watchPosition` → スロットリング(2秒/5m, [02 §2](../02_technical-design.md))→ `position` 送信 |
| 他者の更新 | `member_update` で該当ピン/一覧を更新。`member_joined`/`member_left` で増減 |
| **メンバー一覧** | 引き上げで一覧シート。各行=名前 / 階(例「1号館3F」)/ 現在エリア or **圏外**。タップで地図をその人へ寄せる |
| **残り時間** | `expires_at` からカウントダウン。`room_expired` 受信で [08 終了状態](./08_states-and-errors.md) |
| 地図FAB | [現在地へ]=自分を中心に / [全員表示]=**現在エリア内**の全員が収まる縮尺(別エリアの人は圏外扱い) |
| 階変更(`FloorSelector`) | 建物(任意)+階を変更 → `floor`(`building_id`/`floor`)送信 |
| 操作バー | 集合場所([06](./06_meeting-and-places.md))/ 建物([05](./05_building-panel.md))/ 空き教室([06](./06_meeting-and-places.md))/ 共有・設定([07](./07_room-settings.md))/ [退出]([07](./07_room-settings.md)) |

- [建物]は **キャンパスエリアのとき**のみ有効(駅エリアでは無効化)
- 集合場所が設定されている時、各参加者→集合地点のおおよその距離を表示([企画書 4.4](../imasoko-kikakusho.md))

## API / WS

```
GET /api/campus                → { areas, buildings }        # 参加後に取得(建物/教室・エリア名)
WS 送信 : position / floor / (各シートのメッセージは 05〜07)
WS 受信 : room_state / member_joined / member_update / member_left
          / meeting_point / place_suggestions / room_expired
```

- エリアのSVG・キャリブレーションはフロント定数(`mapAreas.ts`, [05 §1](../05_feature-design.md))、建物/教室マスタはサーバ(`GET /api/campus`)

## 状態・エラー

- 接続断:上部に「再接続中…」インジケータ(バックオフ再接続, [02 §5](../02_technical-design.md))
- 閲覧のみ(位置拒否):自分ピンなし+「閲覧のみ」バッジ。位置許可し直しの導線
- 圏外(全エリア外/選択エリア外):端クランプ+一覧に「圏外」
- `room_expired`:地図を閉じ [08](./08_states-and-errors.md)
