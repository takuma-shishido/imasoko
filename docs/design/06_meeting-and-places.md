# 06 集合場所 & 空き教室(ボトムシート)

関連:[索引](./00_index.md) / [05 §4・§5・§6](../05_feature-design.md) / [企画書 4.4](../imasoko-kikakusho.md)

## 目的

**集合場所を3タイプ(座標 / メンバー / 場所)で指定**し、全員に即共有する。あわせて、参加者がそれぞれ**空いている教室などの候補を追加**し、そこから集合場所を選べるようにする。誰でも設定・追加できる([企画書 4.4](../imasoko-kikakusho.md))。

## 遷移

- 入口:操作バー[集合場所] / [空き教室]、または地図長押し(座標指定)、建物パネルの「集合場所にする」([05](./05_building-panel.md))
- 出口:ハンドルのドラッグ / 背景タップ / 設定完了

## レイアウト(mobile・シート)

```
╭─────── ハンドル ───────╮
│ 集合場所を決める          │
│ ◉ 地図をタップした地点     │  ← coords
│ ○ 誰かのところ  [ゆうた▾] │  ← member(参加者から選択)
│ ○ 場所から選ぶ  [教室/前▾]│  ← place(教室 or「1号館前」)
│           [この場所にする] │
├───────────────────────┤
│ 空いてる教室(みんなで追加) │
│  ・3号館 302「空いてた」🧑 さき │  ← place_suggestions
│  ・1号館 前  🧑 たくま        │
│  [+ 空き教室を追加]          │
╰───────────────────────╯
```

## 集合場所の3タイプ([05 §4](../05_feature-design.md))

| タイプ | 指定方法 | 表示 |
|---|---|---|
| `coords` | 地図をタップ/長押し | その座標に集合ピン |
| `member` | 参加者一覧から選ぶ | 指定メンバーの**現在地に追従**(その人が動けば集合地点も動く) |
| `place` | 教室 or ランドマーク(「1号館前」) | campus マスタの座標に集合ピン(教室は建物位置で近似) |

## 空き教室の追加(crowd-sourced, [05 §4/§5](../05_feature-design.md))

- [+ 空き教室を追加]→ 建物/階/教室を選び(campus マスタ)、任意メモ(例「空いてた」)を付けて `add_place_suggestion`
- 候補は**ルーム内全員に共有**(`place_suggestions`)。誰でも追加でき、そこから[この場所にする]で集合場所へ採用
- マスタは当面手入力CSV([05 §5](../05_feature-design.md))。候補は最新状態のみ保持し、ルーム消滅で消える

## API / WS

```
WS 送信 : { type:"meeting_point", point: <MeetingPoint union> }   # coords|member|place
          { type:"add_place_suggestion", place: <PlaceRef>, note? }
WS 受信 : { type:"meeting_point", point }            # 全員へ反映(null で解除)
          { type:"place_suggestions", items: [...] } # 候補一覧の更新
```

- 型定義(`MeetingPoint` / `PlaceRef` / `PlaceSuggestion`)は [05 §4](../05_feature-design.md)
- `member` 型は座標を再送しない。対象の `member_update` を見てUIが追従表示

## 状態・エラー

- 誰でも上書き可のため、最後の設定が有効(履歴なし)。「◯◯さんが集合場所を変更」の軽い通知を検討
- `member` 対象が退出(`member_left`):集合場所を解除 or 「対象が退出しました」表示
- 教室が campus マスタに無い:追加不可(建物データ整備待ち)
